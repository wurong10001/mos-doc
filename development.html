开发手册

Web 端

cd MOS
npm install
npm run dev

Wrangler 会在本地起一个 Worker。判断 UA 的逻辑在浏览器里不好测， 可以在开发者工具里切设备模拟，或者直接访问 /desktop.html 和 /mobile.html。

Android 端

cd mos-android
./gradlew assembleDebug

原生库不走 NDK 现场编译，是预编译好放进 jniLibs 的。 所以改了 C++ 之后要重新编一次 .so 再拷过去，光跑 gradlew 不会生效。

环境

端 需要什么 备注
Web Node.js、Wrangler 有 Cloudflare 账号才能部署
Android Android Studio、Gradle、CMake 编译目标 30，NDK 只在重新编 .so 时需要
文档站 浏览器 改完推 main，GitHub Pages 自己更新

改代码前先知道

  • Web 端没有构建步骤，HTML 就是最终产物，改完刷新即可
  • Android 端的 C++ 改动要手动重编 .so，这是最容易踩的一步
  • sample.wasm 是唯一能跑的模块，加新模块先照着它的调用方式写
  • Wasm 和原生层之间没有接口约定，改这块前最好先在文档里把约定写下来
