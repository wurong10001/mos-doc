开发手册

开发环境

  • Web 端：Node.js + Wrangler
  • Android 端：Android Studio / Gradle / CMake / NDK
  • 文档站：GitHub Pages（静态站点）

Web 端构建

cd MOS
npm install
npm run dev

由 `wrangler` 提供 Cloudflare Workers 托管能力。页面会根据 UA 自动选择桌面或移动端 shell。

Android 端构建

cd mos-android
./gradlew assembleDebug

当前工程通过 `app/build.gradle` 和 `CMakeLists.txt` 进行构建，并将原生库放入 `jniLibs` 目录以适配特定环境。

推荐开发流程

  1. 先理解 MOS 的三层架构：UI / 接入 / 运行时。
  2. 使用 `MOS` 仓库做界面草稿与交互验证。
  3. 在 `mos-android` 中确认原生层与运行时行为是否一致。
  4. 把稳定模块收录进 `mos-repo`。
  5. 用 `mos-doc` 统一整理设计、开发约定和使用说明。
