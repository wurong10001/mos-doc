这个项目在做什么

把桌面的操作方式搬到浏览器和手机上。Web 端画桌面，Android 端跑原生宿主， 应用逻辑编译成 WebAssembly，交给 wasm3 解释执行。

目前一共 4 个仓库。界面能看，运行时刚跑通一个 sample.wasm，软件源还是空的。

已经能跑的

  • 访问根路径时，Worker 按 UA 分流到 desktop.html 或 mobile.html
  • 桌面端有状态栏、Dock、欢迎页，深蓝主色
  • Android 工程能编译，wasm3 加载 sample.wasm 并执行
  • 文档站本身跑在 GitHub Pages 上

还没有的

  • 桌面上的图标点开后没有真正的应用
  • 没有窗口管理、没有文件管理
  • mos-repo 里只有一个说明文件，没有任何应用包
  • Wasm 模块和原生层之间还没有定义接口

四个仓库

MOS Web 入口。Cloudflare Worker + 静态资源，src/index.js 是全部逻辑所在
mos-android 原生宿主。NativeActivity + C++，CMake 构建，wasm3 解释 Wasm
mos-repo 软件源。预留位置，准备放应用包和模块
mos-doc 就是这个站。架构、开发手册、路线图都记在这里

从哪看起

  1. 想看代码怎么组织的，去 仓库说明
  2. 想理解为什么分成这三层，去 架构设计
  3. 想把项目跑起来，去 开发手册
  4. 想知道接下来做什么，去 路线图
