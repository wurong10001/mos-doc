MOS 教程

这套教程讲的是 MOS：一个想把桌面操作方式搬到浏览器和手机上的项目。 读完你会知道它的四个仓库各自负责什么、一次访问是怎么从浏览器走到界面的、 Android 那边怎么用 C++ 跑起一个 WebAssembly 模块，以及怎么把它跑起来自己改。

这套教程适合谁

如果你想看懂这个项目在干什么，或者想接手改它，按顺序读就行。 需要的基础不多：能读懂 JavaScript 和一点 C++，知道命令行怎么用。 没接触过 WebAssembly 也没关系，第 02 节专门讲。

先说清楚一件事

MOS 现在是个原型。界面能看，Android 工程能编译，Wasm 能加载执行一个示例模块。 但桌面上点开图标没有真正的应用，也没有窗口管理。教程里会明确标出哪些是能跑的、哪些还没有，避免你按成品去理解它。

六个章节

01 开始

这一页。讲这套教程的结构和读法。

02 预备概念

WebAssembly、wasm3、Cloudflare Worker、NativeActivity、NDK 分别是什么。已经懂的可以跳过。

03 系统架构

四个分层怎么划的，一次请求走哪条路，现在哪些地方还没接上。

04 代码在哪

四个仓库各放什么，每个仓库里应该先看哪个文件。

05 动手跑起来

Web 端和 Android 端各自的构建命令、验证方法，以及一个容易踩的坑。

06 继续深入

三个可以自己动手的练习，以及项目接下来的方向。

怎么读

第一次接触就按 01 到 06 顺序读，每节末尾有个小结，答不上来可以回头再看一遍。 只想快速上手，可以跳到 05，卡住了再回来补 02 和 03。

教程里提到的文件路径都是相对各仓库根目录的，比如 src/index.js 指的是 MOS 仓库里的这个文件。

这一节要点

  • MOS 是原型，不是成品，教程会区分「能跑的」和「还没有的」
  • 一共六个章节，按依赖顺序排，不是按时间排
  • 需要的基础：JavaScript、一点 C++、命令行
