Overview

一个面向桌面体验与跨平台运行的系统原型

MOS 当前呈现为“云端桌面 + Android 宿主 + WebAssembly 执行层”的混合系统雏形。 它不仅是一套前端界面，也体现了从 UI 原型到系统运行时、再到软件源体系的整体设计思路。

仓库数量 4
核心组件 3
阶段 Alpha

项目定位

MOS 不是普通的单页应用，而是一个以“桌面系统体验”为核心的原型工程。 它尝试通过 Web 端界面、Android 原生宿主，以及 Wasm 执行能力，将桌面操作系统的视觉和运行方式做成一个统一的概念模型。

当前价值

当前价值主要体现在：界面原型、跨终端适配、移动端/桌面端统一体验、以及面向未来扩展的原生 + Wasm 架构探索。 这使 MOS 更像是系统雏形，而不是产品级功能闭环。

系统概览

体验层 桌面 UI / 触屏 UI / 统一视觉语言
入口层 Cloudflare Worker + 静态资源托管
执行层 Android NativeActivity + C++ + wasm3
应用层 软件源仓库 + 模块化扩展能力

关键结论

  • MOS 具有明显的“操作系统化”界面语言。
  • Web 端通过 UA 识别实现桌面/移动端适配。
  • Android 层采用原生宿主 + C++ + Wasm 的执行模型。
  • 仓库体系明显分层：入口、运行时、软件源、文档。
  • 当前阶段更接近系统雏形与概念验证，而非成熟应用平台。
