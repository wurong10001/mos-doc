架构设计

整体分层

层 1：体验层 桌面 UI / 移动端触屏 UI
层 2：接入层 Cloudflare Worker + 静态资源服务
层 3：执行层 Android Native + C++ + Wasm
层 4：应用层 软件源 / 业务模块 / 统一扩展

Web 入口

`MOS` 仓库通过 Cloudflare Worker 接收请求。 如果访问根路径，代码会根据 UA 判断设备类型：桌面端或移动端，然后跳转到对应页面。 

if (url.pathname === '/') {
  const isTouchDevice = /android|iphone|ipad|mobile/i.test(userAgent);
  url.pathname = isTouchDevice ? '/mobile.html' : '/desktop.html';
}

Android 宿主

`mos-android` 采用 NativeActivity + C++ 作为原生宿主层，使用 `wasm3` 来执行 WebAssembly 代码， 使系统具备轻量运行时能力与跨平台扩展潜力。

设计特点

  • 以“桌面系统交互”作为视觉基线，而不是普通网页布局。
  • Web 端和 Android 端的用户感知保持同一系统语言。
  • Wasm 执行能力为后续扩展应用/模块提供底层标准化执行环境。
  • 系统设计允许从 UI 原型逐步演化为完整的应用生态。
