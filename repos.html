仓库说明

MOS

Web 入口，也是目前唯一能公开访问的部分。Worker 加上两个静态页面，代码量很小。

  • src/index.js — 全部服务端逻辑，就一个 UA 判断
  • public/desktop.html — 桌面端界面
  • public/mobile.html — 触屏端界面
  • public/assets/system.css — 两边共用的样式

部署走 Wrangler，推到 Cloudflare Workers 上。

mos-android

原生宿主。工程是标准 Gradle 结构，C++ 部分用 CMake 编。

  • app/src/main/cpp/main.cpp — 主循环
  • app/src/main/cpp/engine.cpp — 引擎调度
  • app/src/main/cpp/wasm_runner.cpp — Wasm 加载与调用
  • app/src/main/assets/sample.wasm — 示例模块

原生库是预编译好放进 jniLibs 的，不在本地走 NDK 编译，这样在 Termux 这类环境也能构建。

mos-repo

打算做软件源的地方。现在除了一个 README 说明"MOS 系统软件源"，里面什么都没有。

要等应用包格式定下来，这个仓库才有东西可放。

mos-doc

你正在看的这个站。纯静态，五个 HTML 加一个 style.css，托管在 GitHub Pages。

改动流程：改 HTML，推到 main，Pages 自动重新部署。

依赖关系

四个仓库之间没有代码依赖，互不 import。它们只是概念上分层 —— 入口在 MOS，运行时在 mos-android，以后的应用包放 mos-repo，说明写在这里。
