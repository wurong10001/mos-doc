第 03 节

桌面与应用

这一节讲日常操作：怎么启动应用、怎么在几个应用之间切换、 应用是从哪来的、以及怎么装新的。

启动应用

MOS 里启动一个应用有三种入口，用哪个都行：

桌面图标

双击桌面区上的图标。这是最常用的一条路。

Dock

点底部应用栏里的图标。常用应用建议放这里，省得回桌面找。

已运行的应用

点 Dock 上带运行标记的图标，直接切回那个应用，不会重复启动。

窗口

应用启动后会在桌面区开一个窗口。窗口顶部是标题栏，右侧是最小化、最大化、关闭。

  • 切换：点另一个窗口的任意位置把它提到前面，或者点 Dock 上对应的图标
  • 最小化：收进 Dock，应用还在运行，点回来就恢复
  • 关闭：退出应用。没保存的内容会丢，关之前留意一下
最小化 ≠ 关闭

最小化的应用仍在后台运行，占着系统资源，但不会再刷新界面。 把它点回来时会接着上一次的状态继续，这是它和关闭最大的区别。

状态栏

屏幕顶部的状态栏一直可见，不会被窗口盖住。它显示当前时间和系统状态， 有通知时会在这里出现提示。

触屏端怎么操作

手机上没有窗口这个概念，一次显示一个应用。从应用退出回到的是应用网格， 在里面点另一个图标就切过去了。已经在后台运行的应用会在网格里标出来。

应用从哪来

MOS 的应用都来自软件源，也就是 mos-repo 这个仓库。 它相当于系统自带的应用商店后台：每个应用是一个包，里面有一个 WebAssembly 模块和一份说明清单。

这样安排的好处是应用来源集中、可审计 —— 你能看到每个应用包里到底有什么， 版本怎么变的，谁提交上去的。

安装与管理

  1. 在软件源里找到想要的应用，每个应用都有一个唯一 id 和版本号。

  2. 安装时系统读取应用的清单，检查它声明需要哪些系统能力，列给你确认。

  3. 确认后应用包被放进系统，图标出现在桌面区和 Dock。

  4. 软件源里出了新版本，可以更新到最新版，也可以退回旧版本。

  5. 不用的应用可以卸载，图标和数据一起移除。

关于权限

应用不能自己拿系统能力。它能用什么是清单里写死、安装时你确认过的。 比如一个计算器应用声明只用到最基本的界面能力，它就没有别的可拿。 这条限制是 WebAssembly 沙箱带来的，在 04 节会细讲。

常用操作对照

想做什么 桌面端 触屏端
启动应用 双击桌面图标或点 Dock 点应用网格里的图标
切换应用 点目标窗口，或点 Dock 图标 退出到网格再点另一个
后台保留 点窗口最小化 直接退出，系统保留状态
彻底退出 点窗口关闭 在多任务列表里划掉
装新应用 从软件源安装 从软件源安装

这一节要点

  • 启动应用有三个入口：桌面图标、Dock、正在运行的实例
  • 最小化是后台保留，关闭才是退出，两者不同
  • 应用全部来自 mos-repo 软件源，一个应用 = 一个 Wasm 模块 + 一份清单
  • 应用能用哪些系统能力由清单声明、安装时确认
