路线图

Phase 1

桌面原型建立

完成桌面 / 触屏界面 shell，并稳定两套视觉风格。

Phase 2

Web 入口服务化

提升 Cloudflare Worker 路由能力，形成统一入口、统一资源加载、统一启动逻辑。

Phase 3

Android 宿主稳定化

完善 Native 层事件循环、日志、崩溃处理、Wasm 运行时管理。

Phase 4

软件源化

以 `mos-repo` 为基础，归档应用、模块与包结构，形成统一软件源。

Phase 5

系统生态扩展

在 Web + Android + Wasm 的基础上，逐步实现文件管理、通知、设置、应用启动器等基本系统能力。
